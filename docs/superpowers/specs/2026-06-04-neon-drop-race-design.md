# 네온 낙하 레이스 룰렛 — 설계 문서

작성일: 2026-06-04
상태: **현행(active)**. 이전 `2026-06-04-vortex-drain-roulette-design.md`는 폐기(superseded).

## 개요

세로로 긴 네온 코스에 이름들이 공이 되어 위에서 투하된다. 핀과 특수 장치를
튕기며 낙하해 바닥 결승선에 도착하고, **도착 순서가 순위**를 결정한다. 시작을
한 번 누르면 멈추지 않고 전원이 도착할 때까지 진행되는 **한 사이클** 룰렛이다.

참조한 lazygyu(고정 맵 세로 핀 낙하)와 같은 "낙하 레이스" 장르지만, **매판 랜덤
생성 코스 + 게임필 주스(카메라·트레일·네온·결승 연출) + 특수 장치 4종**으로
차별화한다.

## 핵심 요구사항

- **운빨 100% 체감**: 아무도 조종하지 않는다. 랜덤 코스 + 랜덤 투하 + 핀 카오스로
  결과를 예측 불가하게 한다.
- **전체 순위**: 도착 순서로 1등부터 꼴찌까지 줄 세운다.
- **한 사이클**: 턴/라운드 반복 없음. 시작 → 연속 낙하 → 종료.
- **인원**: 2~20명.
- **비주얼**: 네온 글로우(어두운 배경 + glow).
- **세 재미 축**: 역전(추월·장치), 카오스(핀 튕김·병목), 탈락/도착 연출.

## 메커니즘

### 물리 모델

- 엔진: matter.js, **아래 방향 중력**. 좌표 y는 아래로 증가.
- 코스는 화면(캔버스)보다 세로로 길다. 카메라가 선두를 따라 스크롤한다.
- 공은 위 깔때기(hopper)에서 랜덤 x, 작은 랜덤 vx로 투하된다.
- 공끼리/핀과 충돌은 반발력으로 통통 튄다 → 카오스.

### 랜덤 코스 생성 (`game/course`)

매판 절차적으로 세로 코스를 생성한다.

- 베이스: 위→아래로 일정 간격 행마다 **엇갈린 핀 격자**(점 장애물). 핀 사이 간격은
  공 지름보다 넓어 항상 통과 가능 → 솔버빌리티 기본 보장.
- 좌우 **벽**(static)으로 코스 가둠. 바닥에 **결승선**(y 임계값).
- 일부 행에 장치 배치(아래). **가로 전체를 막는 장애물은 절대 두지 않는다**(항상 통로).
- 시드는 매 실행 Math.random.

### 특수 장치 4종 (`game/devices`)

1. **회전 범퍼/바람개비(spinner)**: static 막대를 매 틱 `setAngle`로 회전(키네마틱).
   부딪힌 공을 다이내믹하게 튕긴다.
2. **부스터 패드(booster)**: 충돌체 없는 영역(region). 공 중심이 영역 안이면 매 틱
   방향 임펄스(주로 아래/대각) 적용 → 가속·역전.
3. **순간이동 파이프(teleport)**: 입구 영역에 공이 들면 출구로 `setPosition`. 출구
   y는 입구보다 **아래**(순진행 보장), x는 랜덤. 즉시 재발동 방지 쿨다운.
4. **슬로프/깔때기(slope)**: 기울어진 static 벽. 흐름을 한쪽으로 몰아 병목 드라마.
   **항상 공 지름 이상 통로**를 남긴다(가로 전체 차단 금지).

### 종료 보장

- 중력이 낙하를 보장하지만 핀/막대 위에 얹혀 멈출 수 있다.
- **타임아웃 가드**: 일정 시간 경과 시 남은 공을 현재 깊이(y) 순으로 강제 도착 처리.
- (선택) 정지 감지 시 미세 너지. MVP는 타임아웃 가드로 충분.

### 순위 도출

- 내부적으로 **도착 순서 배열**(`finishOrder`) 하나만 유지한다(index 0 = 1등).
- 공이 결승선(y ≥ finishY)을 넘으면 즉시 `finishOrder`에 추가하고 월드에서 제거.
  그 공의 최종 등수는 그 순간 확정(= 현재 도착 인원 번호).
- 결과 모드(당첨/벌칙/전체순위)는 이 배열에 **표시 라벨만** 다르게 입힌다.
  - 당첨: 1등 강조 / 벌칙: 꼴찌 강조 / 전체순위: 리스트.
- 별도 "1등 기준" 토글 없음 — 레이스는 도착 순서가 표준. 꼴찌는 벌칙 모드로 커버.

### 카메라 (`render/camera`)

- 코스가 뷰보다 길다. 카메라 top = 선두(가장 아래) 공 y − 뷰높이·0.4, 코스 범위로
  클램프, 부드럽게 lerp.
- `clampCamera(targetTop, viewH, courseH)` 순수 함수로 분리(테스트).

### 게임필 주스 (`render/renderer`)

- 네온: 어두운 배경 + `shadowBlur` 글로우(공·핀·장치·결승선).
- **트레일**: 공마다 최근 위치 N개 저장해 잔상 폴리라인(알파 감소)로 그림.
- 결승 연출: 결승선 글로우, 1등 강조. (막판 슬로모는 선택/후순위.)
- 카메라 변환 안에서 월드를 그리고, 화면 고정 오버레이는 변환 밖에서.

## UI (`ui/controls`)

- 입력 패널: 이름 텍스트영역(줄당 1명), 시작 버튼, 결과모드(당첨/벌칙/순위).
- 캔버스: 스크롤 코스. 사이드: 도착순 실시간 순위("N위 이름").
- 종료: 최종 순위 오버레이 + 다시하기 버튼.
- 2명 미만이면 시작 버튼 비활성 + 힌트(실시간 갱신).
- 입력 규칙: 빈 줄·공백 무시, 중복 허용, 긴 이름 표시 truncate.

## 기술 스택

- Vite + TypeScript + Canvas + matter.js + vitest. 정적 배포 가능.
- 재사용: `input.ts`(parseNames), `colors.ts`. 나머지는 레이스용으로 재작성.

## 코드 구조

- `physics/world` — matter 엔진(중력 on), 바디 추가/제거, 스텝.
- `game/course` — 코스 타입 + 랜덤 생성(핀·장치·벽·결승선).
- `game/devices` — 장치 효과 적용(spinner 회전, booster 임펄스, teleport 이동).
- `game/ball` — 공 엔티티(+트레일 상태).
- `game/engine` — 루프, 도착 기록, 종료/타임아웃, 카메라 타겟.
- `render/camera` — 카메라 클램프/추적(순수 + 상태).
- `render/renderer` — 네온·트레일·코스·결승 드로잉.
- `ui/controls`, `main`.

## 테스트 (vitest)

- 순수: `parseNames`(재사용), `assignColors`(재사용), `clampCamera`, 코스 생성
  불변식(모든 장애물 경계 내, finishY>startY, 워프 출구 in-bounds & 입구보다 아래,
  슬로프/벽이 가로 전체를 막지 않음), 도착순→순위·모드 라벨.
- **헤드리스 솔버빌리티 sim(핵심 가드)**: 랜덤 코스 다수 생성 → N명 투하 →
  전원 결승 도달 + 타임아웃 내 자연 종료 검증(랜덤 생성이 함정 코스를 만들지 않음을
  경험적으로 보장). 물리/렌더 없이 엔진만 헤드리스 구동.

## 비범위 (이번 버전 제외)

- 직접 코스 편집, SFX(v1 생략/옵션), 무게·개수 가중치, 막판 슬로모(후순위),
  21명+ 대규모 성능 최적화, 다중 결승/스테이지.

## 메모

- "해보고 재미없으면 바꾼다" 기조 유지. 랜덤 생성·장치·주스 파라미터는 헤드리스
  sim과 브라우저 검증으로 튜닝.
