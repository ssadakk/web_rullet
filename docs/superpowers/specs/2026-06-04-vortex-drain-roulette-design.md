## 개요

위에서 내려다보는 둥근 보울(bowl)에 이름들이 공이 되어 풀려난다. 공들은
빙빙 소용돌이치다 궤도가 안으로 말려 중앙 배수구 구멍 하나로 하나씩 빨려든다.
빠지는 순서가 최종 순위를 결정한다. 시작을 한 번 누르면 멈추지 않고 전원이
빠질 때까지 진행되는 **한 사이클** 룰렛이다.

lazygyu 룰렛(세로 핀 낙하 레이스)과는 메커니즘·비주얼이 완전히 다르다.

## 핵심 요구사항

- **운빨 100% 체감**: 아무도 조종하지 않는다. 물리 카오스 + 매판 랜덤 초기조건으로
  결과를 예측할 수 없게 한다. (스킬 요소 없음)
- **전체 순위 도출**: 빠지는 순서로 1등부터 꼴찌까지 줄 세운다.
- **한 사이클**: 턴/라운드 반복 없음. 시작 → 연속 모션 → 종료.
- **1등 기준 유저 선택**: "먼저 빠짐 = 1등" 또는 "마지막 빠짐 = 1등"을 유저가 고른다.
- **인원**: 2~20명.
- **비주얼 톤**: 미니멀·기하학.

## 메커니즘

### 물리 모델

- 엔진: matter.js, 전역 중력 0 (탑다운).
- 매 스텝 각 공에 **중심 방향 인력**을 가한다(깔때기 경사 모사).
- 공은 시작 시 랜덤 위치 + 랜덤 접선 속도를 받아 공전한다.
- 공끼리 충돌은 반발력 높게 → 궤도가 통통 교란되어 카오스 발생.
- 시간이 지나면 인력을 점증시키거나 배수구 반경을 확대해 궤도가 안으로
  수렴하도록 한다 → **유한 시간 종료 보장**. 추가로 타임아웃 가드를 둔다.

### 배수구 / 빠짐 판정

- 보울 중앙에 작은 배수구(sensor 영역).
- 공이 배수구 영역 안에 들어오면 "빠짐"으로 처리: 월드에서 제거하고 빠짐 순서에
  기록한다.
- 빠질 때 시각적으로 작아지며 사라진다.

### 순위 도출

- 내부적으로 **빠짐 순서 배열** 하나만 유지한다.
- 유저의 "1등 기준" 선택에 따라 배열 방향만 결정한다:
  - "마지막 빠짐 = 1등"(기본값): 빠짐 순서의 역순이 순위.
  - "먼저 빠짐 = 1등": 빠짐 순서 그대로가 순위.
- 결과 모드(당첨/벌칙/전체순위)는 이 순위 배열에 **표시 라벨만** 다르게 입힌다.
  내부 로직은 하나다.
  - 당첨: 1등 강조
  - 벌칙: 꼴찌 강조
  - 전체순위: 전체 리스트

## UI

- **입력 패널**
  - 이름 텍스트영역(줄당 1명).
  - 시작 버튼.
  - 결과모드 토글: 당첨 / 벌칙 / 전체순위.
  - "1등 기준" 토글: 먼저 빠짐 ↔ 마지막 빠짐.
- **캔버스**: 보울 링 + 중앙 구멍 + 소용돌이치는 공 애니메이션.
- **사이드**: 진행 중 빠진 순서대로 실시간 순위 누적.
- **종료**: 최종 순위 오버레이 + 다시하기 버튼.

### 입력 규칙 / 에러 처리

- 빈 줄·앞뒤 공백 무시.
- 중복 이름 허용.
- 긴 이름은 표시상 truncate(데이터는 보존).
- 유효 이름 2명 미만이면 시작 버튼 비활성 + 힌트 표시.

## 기술 스택

- Vite + TypeScript + Canvas + matter.js.
- 정적 배포(GitHub Pages 등) 가능 구조.

## 코드 구조 (독립·테스트 가능 단위)

- `physics/world` — matter.js 엔진 생성·스텝 진행.
- `game/ball` — 공 엔티티(물리 바디 + 이름 + 색 + 상태).
- `game/drain` — 보울 지오메트리, 중심 인력 적용, 빠짐 판정, 종료 보장 로직.
- `game/engine` — 게임 루프 오케스트레이션, 빠짐 순서 기록, 종료·결과 도출.
- `render/renderer` — 캔버스 드로잉(보울, 공, 구멍, 라벨).
- `ui/controls` — 입력·설정·시작·결과 오버레이·실시간 순위.
- `main` — 배선.

각 단위는 한 가지 책임을 가지며 잘 정의된 인터페이스로 통신한다.

## 테스트 (vitest)

순수 로직만 단위 테스트한다. 물리·렌더는 수동·통합 확인.

- 입력 파싱(줄 분리, 빈 줄·공백 제거, trim).
- 순위 도출(빠짐 순서 + 1등 기준 → 순위 배열).
- 결과 모드 라벨링.
- 색 배정.
- 중심 인력 계산.

## 비범위 (이번 버전에서 제외)

- 싸움/HP/아이템 메커니즘.
- 다중 배수구·포켓 칸(정통 룰렛 보울).
- 맵/코스 디자인, 랜덤 코스 생성.
- 21명 이상 대규모 성능 최적화.

## 메모

- "해보고 재미없으면 바꾼다" — MVP로 빠르게 구현해 손맛 확인 후 방향 조정 가능.
- 운빨 체감을 위해 물리 카오스를 쓰되, 완전 균등 확률은 보장하지 않는다(매판 랜덤
  초기조건으로 편향 최소화). 추후 진짜 균등이 필요하면 결과를 먼저 균등 추첨하고
  애니메이션을 거기 맞추는 "연출용" 모드를 옵션으로 추가할 수 있다.
